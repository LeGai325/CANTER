# Third-party provenance

`specnet/vendor/hotpot_evaluate_v1.py` is the upstream HotpotQA scorer.
Its repository, revision, content hash and import status are preserved in
`specnet/vendor/HOTPOT_SCORER_SOURCE.json`. Consult that upstream project for the
applicable license and attribution terms. The vendored file is unmodified.

HotpotQA and Natural Questions datasets are not bundled; their upstream terms apply.
Python libraries are declared as dependencies and are not copied into this artifact.
No project-wide open-source license has been selected in this prepared snapshot.
