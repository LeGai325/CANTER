# Artifact status

The authors have confirmed that the supplied method implementation was used for
subsequent larger-scale experiments. The source is therefore suitable as the
basis of this method-review release; no further source version is being assumed.

The materials included in this particular export are more limited than a complete
paper reproduction bundle. It contains the recorded 150-question study driver,
portable configurations, tests and documentation. The paper reports 3,000 questions
per configuration, while the exact large-run launcher/configuration, frozen ID
lists and output records have not been supplied with this export.

See [experiment scope](EXPERIMENTS.md) for concrete counts and implemented settings.
Author confirmation of code provenance is distinct from the local installation and
offline checks recorded under `verification/`; neither is an independent rerun of
the manuscript tables. No large-run records were generated during packaging.
